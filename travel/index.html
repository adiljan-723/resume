      03 / 实现方式

      行程背后的工程设计

      导游推荐

      按城市和已确认条件建议不同的玩法。用户确认后，偏好和搜索词才会交给后续 Agent。

      多轮需求澄清

      将预算、日期和偏好存成结构化状态。访客回复「不含住宿」时，只更新对应字段。

      多 Agent 与 MCP

      天气、预算、地点检索各有工具权限。规划使用工具返回的事实，路线检查与内容评审分别记录。

      修订与故障恢复

      改一顿饭后重新检查相关转场。遇到路线查询失败时保留草案，并支持只重查失败路段。
